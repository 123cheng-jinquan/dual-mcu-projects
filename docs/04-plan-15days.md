## 2. 模型路线：我帮你把关的结论

**决定：主任务 = 电机/风扇振动异常分类；输入 = F411 侧算好的 36 维特征；模型 = 小 MLP（int8）+ TFLite Micro。**

为什么不是手势识别：

| 维度 | 振动异常分类（选定） | 手势识别 |
|---|---|---|
| 数据来源 | **自产、可复现**：同一配重/同一螺丝松紧可反复采，30 分钟就能采完 3 类 × 70 组 | 需要人操作，样本一致性差，标注质量不可控 |
| 与 Modbus 工业语境的关联 | **天然契合**：预测性维护是工业网关最标准的 AI 落地场景，不必解释 | 要额外解释"为什么工业网关要做手势" |
| 演示效果 | 拧松一颗螺丝 → 5 秒内屏幕报警，**不依赖演示者手法** | 依赖演示者摇得标不标准，翻车概率高 |
| 工时风险 | 特征只有 36 维、样本 200 组 → 训练 1 分钟、量化几乎不掉点、MCU 推理 <1ms | 输入 600 维、需要更多样本与正则化调参 |
| 加分面 | 双通道对比、阈值 vs 模型、F411 侧 FFT、量化部署，**一个都不少** | 同样的加分面，但风险更高 |

**为什么用"特征 → 小 MLP"而不是"原始窗口 → 1D-CNN"**：在 47 小时的预算里，特征路线的确定性高得多；而且 F411 侧做 FFT + 统计量、只把 36 维传上去，正好讲清**"边缘侧做特征、网关侧做推理"的分层架构**——这本身就是工程判断力，比"把原始数据全丢给模型"更能体现水平。1D-CNN 留作加分项 3，两条通道的对比实验反而是最好的面试素材。

### 2.1 振动任务的落地细节（照做即可）
1. **安装**：MPU6050 用热熔胶/双面胶**刚性固定**在风扇支架或小马达外壳上。软连接会滤掉高频成分，特征全废——这是本任务唯一的"必须做对"的物理条件。
2. **三种状态**（每类 60~80 个窗口）：
   - `normal` 正常空载运转
   - `unbalance` 不平衡：扇叶一侧夹个小夹子或贴一小块橡皮泥
   - `loose` 松动：固定螺丝拧松半圈，或垫一小片纸
3. **采样参数**：50Hz、2s 窗（100 点 × 6 轴）。**固定风扇供电电压/PWM**——转速变化会主导特征，让"不平衡"和"转速不同"混淆（这一点面试可以主动讲，是很好的工程讨论）。
4. **特征**（F411 侧 CMSIS-DSP，128 点实数 FFT）：6 轴 × {均值, 标准差, 峰峰值, 过零率, 主频, 主频带能量占比} = **36 维**。
   ⚠️ **写入顺序必须是 `per-feature`（每个特征 6 轴连续）**，权威定义见 `docs/02` §5-E。写成 `per-axis` 是转置关系——模型照跑不报错，但准确率掉到随机，这是本项目最隐蔽的坑。
5. **训练**：`tools/train_mlp.py` → 标准化参数随模型一起导出（MCU 必须用同一套均值/方差）→ int8 全整数量化 → `model_data.cc`。
6. **评估**：留独立测试集，打印混淆矩阵，目标准确率 ≥90%。把混淆矩阵截图放进 README。

> 采集与训练**完全不依赖 S3**：F411 加一个"打点模式"，用 USART1(CH340) 直接把窗口打到 PC 存 CSV。这样屏幕物流慢也不阻塞进度。

## 3. 屏幕与采购（**今天下单，物流期正好做 F411 侧**）

### 3.1 你手上这块 S3 板（已核对原理图，结论确定）
板型：**`ESP32-S3-CORE-BOARD-V1.4`**，模组 **ESP32-S3-WROOM-1 N16R8**。

- ❌ **板上没有任何屏接口**：无 FPC 排座，全图没有 `LCD_*`/`TFT_*` 网络 ✗ → **必须自己用杜邦线接 SPI 模组**（按 3.2 的表买即可）。
- ⚠️ **GPIO33~37 绝不能用**：N16R8 是 **Octal（8 线）PSRAM**，这 5 个脚被它**独占** ✗✗（图纸上引到了排针，但在这块板子上是废的 —— 这是选屏时最容易踩的坑）。
- **可用 IO**：`0~21`（22 个）+ `38~42`、`45~48`（9 个）≈ **31 个** ✓
  - 避开 `48`（板载 WS2812）、`0/3/45/46`（strapping，做 CS 时注意上电电平）、`43/44`（串口控制台）、`19/20`（USB）
- ✅ **内置 USB-JTAG**：下载与调试只要一根 USB 线，**不用买调试器** ✓
- ⚠️ 板载 USB 转串口是 **CH343**（不是 CH340）→ 首次插上若不出 COM 口，去 wch.cn 装 CH343 驱动。
- 扩展排针 **J1 / J2 各 22 针**，丝印直接标 IO 编号，接线时对着丝印即可。
- ✅ **PSRAM 8MB 已确认**（N16R8 就是 16MB Flash + 8MB Octal PSRAM）→ LVGL 帧缓冲 + TFLite arena 都够 ✓

### 3.2 屏幕选购规格（自己配的话）
| 项 | 建议 | 原因 |
|---|---|---|
| 驱动 IC | **ST7789** 或 **ILI9341** | LVGL / TFT_eSPI 支持最成熟，例程最多 |
| 尺寸/分辨率 | **2.4" 240×320** 为甜点 | 字够大、PSRAM 压力小；1.9" 布局偏挤 |
| 接口 | **SPI 四线** | 引脚少、S3 够用；**不要 8080 并口或 RGB 并口**（吃 16+ 引脚和带宽） |
| 触摸 | 电容触摸（I2C，CST816/FT6236）优先；电阻触摸（XPT2046, SPI）更便宜但体验差 | 电容触摸的 LVGL 例程更新更勤 |
| 逻辑电平 | 3.3V | S3 是 3.3V，5V 逻辑屏要加电平转换 |
| 避坑 | 别买"裸屏无驱动 IC"、别买 MIPI 屏（S3 不支持） | — |

**两条路线**：
- **省钱路线（推荐）**：买"2.4" SPI TFT + 电容触摸模块"（约 40~70 元），用手上那块 S3 板。代价：自己配 `TFT_eSPI` 的 `User_Setup.h` + 触摸校准，约半天。
- **省时路线**：买 **ESP32-S3 + LCD 一体板**（微雪/合宙等，含触摸，约 100~150 元）。例程现成，省 1~2 天；代价是手上的板子闲置。
- **判断标准**：你 15 天只有 45~55 小时，**1.5 天 ≈ 6 小时**。如果 60~100 元差价对你无所谓，直接上一体板；如果想省钱且愿意花半天配驱动，走省钱路线。

### 3.3 必买清单（合计约 90~160 元）
| 物品 | 预算 | 为什么必须 |
|---|---|---|
| **USB 转 RS485 调试器** | 15~25 | **最容易被忽略但最不能省**：没有它，阶段 3 无法独立验证，只能等 S3，风险翻倍 |
| 带 DE/RE 引脚的 485 模块 或 MAX3485 ×2 | 10~25 | 套件里的 485 模块若是自动收发，就练不到手写 DE 时序（那是简历卖点） |
| 外部 5V/2~3A 电源 + DC 座 + 470µF 电解 + 0.1µF | 25~40 | 舵机/电机/风扇独立供电，否则随机复位 |
| 电阻包（1k/4.7k/10k/20k）+ 面包板电源模块 | 15~25 | 分压（MQ 系列 AO、HC-SR04 ECHO 必须分压）、I2C 上拉 |
| 屏幕（见 3.2） | 40~150 | 人机界面 |
| 可选：8CH USB 逻辑分析仪 | 20~30 | 485/时序问题排错提速巨大，性价比极高 |

## 5. 每天开工前的 3 条纪律
1. **先验收上一阶段**：上一阶段的验收标准没过，不开新模块（否则问题会叠加，最后无法定位）。
2. **能拆到 PC 上验证的绝不留给联调**：CRC 用 Python 对拍、从机用 PC 主机测、主站用 PC 从机模拟器测。
3. **改完就提交 Git**，commit 信息写清模块（面试时提交历史也是素材）。
