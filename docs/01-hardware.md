## 1. 板载已占用引脚（不要复用）

| 引脚 | 板载外设 | 备注 |
|---|---|---|
| PA9 / PA10 | USART1 → CH340N | 调试串口。**Modbus 必须改用 USART2** |
| PA11 / PA12 | USB OTG FS | 备用（可做 USB CDC 打点） |
| PA13 / PA14 | SWDIO / SWCLK | 下载调试，保留 |
| PH0 / PH1 | HSE 晶振 | — |
| PC14 / PC15 | LSE 32.768kHz | — |
| PC13 | LED_T（LED1~4 共用） | 板载运行指示 |
| PA0 | KEY1 板载按键 | 保留为本地按键（打标/模式切换） |
| PB12 / PB13 / PB14 / PB15 | SPI2 → W25Q128(16MB) | **套件里的 W25Q64 模块不用接**；这 4 个脚视为被占用 |
| PB3 / PB4 / PB5 / PC12 / PD2 / PA15 | SPI1 → LCD FPC | **不插板载屏则全部空出** |
| PB6 / PB7 / PB8 / PB9 | I2C1 → 电容触摸 | **不插触摸屏则全部空出**（PB6/PB7 拿来当传感器 I2C） |

> 结论：不插板载 LCD/触摸屏时，可用 GPIO 约 **35 个**，足够本项目。

### 1.1 下载调试口（原理图实测）★接线必读

板上有一组**独立的 4 针 SWD 排针**（不在 H2/H3 里），从上到下：

| 针 | 网络 | 接到调试器（ST-Link / DAP-Link） |
|---|---|---|
| 1 | **3V3** | 3.3V |
| 2 | **SWDIO** | SWDIO（= PA13） |
| 3 | **SWCLK** | SWCLK（= PA14） |
| 4 | **GND** | GND |

- ⚠️ **不要把调试器的 5V 接到板子的 3V3**（ST-Link 的 10 针座上有 5V 脚，别接错）
- ⚠️ 报错 `Unable to get core ID` / `init mode failed (unable to connect to the target)` 时：
  **"能测到 3.25V 电压、却拿不到 core ID"就是 SWDIO 与 SWCLK 接反或没插紧的典型症状**。
  反接不会烧坏，换过来即可。
- 本项目实测用 **ST-Link V2（VID:PID 0483:3748）**：`STM32CubeCLT` 自带的
  `STM32_Programmer_CLI` 与 MSYS2 的 `openocd` 都能直接驱动，**无需另装驱动**。
- 串口调试走 **CH340 那一路 Type-C**（PA9/PA10），插上后设备管理器里应出现一个 COM 口；
  **烧写只需要 SWD 那 4 根线，串口线是另外插的**，两者互不影响。

## 4. 外设资源分配表（写进 CubeMX）

| 外设 | 引脚 | 配置要点 |
|---|---|---|
| **ADC1** | PC0–PC5, PB0, PB1 | 8 通道 **扫描 + DMA 循环**；采样时间 ≥84 cycles；VDDA 加 0.1µF+1µF 去耦 |
| **I2C1** | PB6=SCL, PB7=SDA | 400kHz；MPU6050(0x68)、MAX30102(0x57)、BMP280(0x76)、SSD1306(0x3C)、VL53L0X(0x29) |
| **USART2** | PA2=TX, PA3=RX | **Modbus RTU 从机**；**115200** 8N1（9600 仅作链路自检，原因见 `docs/02` §1.1）；开 IDLE 中断 + DMA |
| **GPIO 输出** | PA1 | RS485 DE/RE，在 **TC 中断**里翻转 |
| **TIM3** | CH1=PA6, CH2=PA7, CH3=PC8, CH4=PC9 | CH1/CH2：1kHz PWM（风扇/电机）；CH3/CH4：RGB G/B（可 1kHz） |
| **TIM1** | CH1=PA8 | RGB 的 R 通道 PWM |
| **TIM2** | CH1=PA5 | **SG90 舵机：50Hz，0.5~2.5ms 脉宽** |
| **GPIO 输入** | PA4(人体感应), PB2(人体雷达), PA0(KEY1) | PA4/PB2 用上拉/下拉按模块输出电平定 |
| **GPIO 输出** | PC10, PC11(电机方向), PC12(蜂鸣器), PD2(状态灯), PA15(备用) | — |
| **USART1** | PA9/PA10 | 调试 printf + **数据集打点**（与 485 链路并行，很重要） |
| **SPI2** | PB12–PB15 | 板载 W25Q128，断网缓存（v0.4 再用） |
| **CAN1** | PB8=RX, PB9=TX | v1.1 协议转换（需 CAN 收发器模块） |
| **IWDG** | — | 必开，~2s 超时 |
| **FreeRTOS** | — | 见 `plan.md` §7.1；每任务栈大小写进 README |

**不用的引脚**：PA9–PA12(调试/USB)、PA13/PA14(SWD)、PC13(板载 LED)、PB3/PB4/PB5/PB12–PB15(SPI)、PC6/PC7(备用)。

## 5. 电平与供电（**红线，违反必出玄学问题**）

1. **3.3V 逻辑，绝不直接接 5V 信号**
   - MQ-2 / MQ-135 的 `AO` 在 5V 供电下可摆到 ~5V → **必须分压**（如 20k 上 / 10k 下，或 10k/20k），再进 ADC
   - **HC-SR04 的 ECHO 是 5V 输出** → 必须分压到 3.3V 再进 GPIO（TRIG 可 3.3V 直驱）
   - 有源蜂鸣器若为 5V 型 → 用 NPN/MOS 管驱动，不要 GPIO 直驱
2. **执行器独立供电**
   - 舵机、风扇、小马达全部用**外部 5V/3A**，**与 MCU 共地**
   - 电机驱动电源端并 **470µF 电解 + 0.1µF 瓷片**；电机两端加续流二极管/RC 吸收
   - 面包板供电轨不要串舵机电流；舵机堵转可达 700mA~1A
3. **分压型传感器需要分压电阻**
   - 光敏电阻、NTC 热敏电阻都是"阻值随物理量变化"，**必须串一个固定电阻构成分压**才有电压输出；电位器直接取中间抽头
4. **I2C 上拉只有一组**
   - 多个模块各自带上拉，并联后阻值过小会拉不动总线；实测静态高电平，必要时去掉模块上拉，只留 4.7k
5. **RS485**
   - A→A、B→B、**GND 必须互联**、双绞线、两端 120Ω（短线可只在一端）
   - 与电机线分开走线，别平行捆扎
6. **上电顺序**：先接 GND → 再 3V3/5V → 最后信号线；断电反序。**每次改接线先断电。**

## 6. 上电前检查清单
- [ ] 万用表量 3V3 与 GND 无短路
- [ ] MQ 系列 AO 分压后实测 ≤3.3V
- [ ] HC-SR04 ECHO 分压后实测 ≤3.3V
- [ ] 485 A/B 未接反（接反不会烧，但收不到数据）
- [ ] 所有模块与 MCU **共地**
- [ ] 舵机/电机用外部电源，且外部电源 GND 与 MCU GND 相连
- [ ] DE 引脚上电默认电平 = 接收态（低）
