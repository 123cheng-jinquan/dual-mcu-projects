新增项目二：双 MCU 声纹识别门禁系统 + 演示素材

把毕业设计升级为端侧全离线的声纹识别系统，并整理进本仓库。

## 新增 voice-lock/（项目二）

架构：STM32F103RET6（8 kHz 采集 + VAD）⇄ UART ⇄ ESP32-S3（MFCC + 比对）⇄ OLED

采集节点（firmware-stm32-ret6）：
- TIM2 比较输出硬件触发 ADC，配合 DMA 循环搬运 16384 点滚动缓冲，
  实测采样率 7996–8000 Hz，采样过程不占 CPU
- 基于帧能量的 VAD 语音触发，噪声底用最小值统计法估计（取最近 10 帧最小值），
  避免噪声底被正在说的话音污染
- 自研二进制帧协议（帧头 + 命令 + 序号 + 长度 + CRC16-Modbus），
  1 秒音频分 32 块上传；接收侧用「滑动帧头 + 长度校验 + CRC 两级校验」
  的非阻塞状态机，实测 66 帧 crcErr=0、零重传、零丢块
- 完整门禁流程：采集 → 上传 → 等判定 → OLED 显示 PASS / FAIL

声纹引擎（firmware-esp32-voicelock）：
- 完全自研 MFCC 链路：预加重 → 25 ms 分帧 / 10 ms 步进 → 汉明窗 →
  自写 256 点基 2 迭代 FFT → 26 个 Mel 三角滤波器 → 取对数 → DCT-II
- 42 维动态特征（14 静态 + 14 Δ + 14 ΔΔ），每维取均值与标准差构成 84 维超矢量
- 比对：全局 z-score + 加权欧氏距离 + 高斯核，并提出 σ 自动标定
  （由注册样本两两距离中位数反解 σ²，使本人正常波动对应约 0.85 相似度）
- 模板持久化到 NVS，带 magic 版本校验（防特征维度变更后读到脏数据）

## 实测结果

- 本人相似度 0.59–0.73，他人 0.49–0.52，区分度约 0.2
- MFCC 自检：自比 1.0000 / 互比 0.7319，验证 FFT 与滤波器组实现正确
- 同人模板一致性 0.830–0.879
- 单次验证端到端约 1.3 秒（采集 1 s + 上传 0.72 s + 推理 56 ms）
- Flash 44 KB / 512 KB，RAM 55248 B / 64 KB
