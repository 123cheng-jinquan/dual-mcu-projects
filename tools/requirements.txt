# --- Modbus 主机/从机（阶段 3/4）---
# 版本区间是**实测出来的**，不是保守估计：
#   * 3.7 ~ 3.9：modbus_slave_sim.py 使用的 ModbusSlaveContext + 数据块注入接口可用，
#     且服务端支持 custom_pdu（本脚本靠它把数量越界/只读区写入做成异常 02/03）。
#   * 3.10 起：pymodbus **删除了 ModbusSlaveContext / ModbusSequentialDataBlock**
#     （改用全新的 SimData/SimDevice API），模拟器会启动失败 → 必须 < 3.10。
#   * 3.6.x：服务端不接受 custom_pdu，功能码覆盖（异常 01）与数量边界会弱化 → 建议 >= 3.7。
# API 差异：3.x 用 framer=FramerType.RTU、read_holding_registers(address, count=, slave=)；
#   3.7 起 FramerType 从 pymodbus.framer 导入；2.x 是 unit= 且无 framer=，整体不兼容。
pymodbus>=3.7,<3.10
